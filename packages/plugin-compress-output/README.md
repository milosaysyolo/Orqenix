# @orqenix/plugin-compress-output

Type-aware compression of tool execution outputs

## Installation

```bash
npm install @orqenix/plugin-compress-output
# or
pnpm add @orqenix/plugin-compress-output
```

## Usage

```typescript
import {} from /* exports */ "@orqenix/plugin-compress-output";
```
