# @orqenix/plugin-knowledge-workflow

Agent-agnostic knowledge workflow: pre-task briefing + post-task reindex

## Installation

```bash
npm install @orqenix/plugin-knowledge-workflow
# or
pnpm add @orqenix/plugin-knowledge-workflow
```
