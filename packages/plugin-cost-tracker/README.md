# @orqenix/plugin-cost-tracker

Track token usage and cost per agent, scope, and session

## Installation

```bash
npm install @orqenix/plugin-cost-tracker
# or
pnpm add @orqenix/plugin-cost-tracker
```

## Usage

```typescript
import {} from /* exports */ "@orqenix/plugin-cost-tracker";
```
