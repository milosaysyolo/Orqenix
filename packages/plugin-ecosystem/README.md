# @orqenix/plugin-ecosystem

Merged ecosystem plugins for Orqenix.

Includes plugins for conformance, cost-tracker, knowledge-workflow, lazy-loader, picker, semantic-cache, and snapshot. Each plugin follows the Orqenix plugin contract and integrates with the marketplace and normalization engine.

## Installation

```bash
npm install @orqenix/plugin-ecosystem
# or
pnpm add @orqenix/plugin-ecosystem
```

## Usage

```typescript
import {} from "@orqenix/plugin-ecosystem";
```
