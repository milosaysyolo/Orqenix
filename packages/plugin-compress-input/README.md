# @orqenix/plugin-compress-input

Compress input to LLM: whitespace cleanup, dedup, optional pseudo-code, concision instructions

## Installation

```bash
npm install @orqenix/plugin-compress-input
# or
pnpm add @orqenix/plugin-compress-input
```

## Usage

```typescript
import {} from /* exports */ "@orqenix/plugin-compress-input";
```
