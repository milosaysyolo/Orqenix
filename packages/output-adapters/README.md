# @orqenix/output-adapters

Apache-2.0 output adapters for Orqenix normalization.

CSF G-compliant adapters targeting 8 platform output formats with round-trip fidelity. Converts canonical intermediate representations into platform-specific output formats.

## Installation

```bash
npm install @orqenix/output-adapters
# or
pnpm add @orqenix/output-adapters
```

## Usage

```typescript
import {} from "@orqenix/output-adapters";
```
