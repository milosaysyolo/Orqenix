# @orqenix/plugin-semantic-cache

Cache identical LLM calls to avoid redundant cost

## Installation

```bash
npm install @orqenix/plugin-semantic-cache
# or
pnpm add @orqenix/plugin-semantic-cache
```

## Usage

```typescript
import { /* exports */ } from "@orqenix/plugin-semantic-cache";
```
