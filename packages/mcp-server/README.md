# @orqenix/mcp-server

Expose Orqenix as an MCP server so editors can consume it

## Installation

```bash
npm install @orqenix/mcp-server
# or
pnpm add @orqenix/mcp-server
```

## Usage

```typescript
import { /* exports */ } from "@orqenix/mcp-server";
```
