# @orqenix/gate-runner-core

Shared base for Orqenix charter gate runners (G1 through G35)

## Installation

```bash
npm install @orqenix/gate-runner-core
# or
pnpm add @orqenix/gate-runner-core
```

## Usage

```typescript
import {} from /* exports */ "@orqenix/gate-runner-core";
```
