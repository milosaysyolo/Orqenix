# @orqenix/plugin-host

Orqenix plugin host: registry + loader lifecycle

## Installation

```bash
npm install @orqenix/plugin-host
# or
pnpm add @orqenix/plugin-host
```

## Usage

```typescript
import {} from /* exports */ "@orqenix/plugin-host";
```
