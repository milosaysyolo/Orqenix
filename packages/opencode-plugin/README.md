# @orqenix/opencode-plugin

OpenCode plugin that bridges to Orqenix daemon

## Installation

```bash
npm install @orqenix/opencode-plugin
# or
pnpm add @orqenix/opencode-plugin
```

## Usage

```typescript
import {} from /* exports */ "@orqenix/opencode-plugin";
```

## API

See https://orqenix.dev/docs/api for full documentation.
