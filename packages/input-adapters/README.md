# @orqenix/input-adapters

Apache-2.0 input adapters for Orqenix normalization.

Supports 14 source formats conforming to the CSF (Common Skill Format) G specification. Converts diverse input sources into a canonical intermediate representation for downstream processing.

## Installation

```bash
npm install @orqenix/input-adapters
# or
pnpm add @orqenix/input-adapters
```

## Usage

```typescript
import {} from "@orqenix/input-adapters";
```
