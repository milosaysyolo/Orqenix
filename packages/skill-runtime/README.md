# @orqenix/skill-runtime

Apache-2.0 skill runtime for Orqenix.

Executes CSF skills via the plugin sandbox. Handles skill lifecycle, input/output validation, sandboxed execution, and result collection. Used as the execution engine behind the Orqenix skill system.

## Installation

```bash
npm install @orqenix/skill-runtime
# or
pnpm add @orqenix/skill-runtime
```

## Usage

```typescript
import {} from "@orqenix/skill-runtime";
```
