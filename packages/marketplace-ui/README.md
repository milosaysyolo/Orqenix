# @orqenix/marketplace-ui

Apache-2.0 shared Marketplace UI components for Workbench and Cloud Control Plane.

React components for browsing, installing, and managing plugins and skills via the Orqenix marketplace.

## Installation

```bash
npm install @orqenix/marketplace-ui
# or
pnpm add @orqenix/marketplace-ui
```

## Usage

```typescript
import {} from "@orqenix/marketplace-ui";
```
