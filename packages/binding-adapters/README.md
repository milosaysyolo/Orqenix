# @orqenix/binding-adapters

Apache-2.0 Orqenix platform binding adapters.

Supports agent runtime bindings for aider, claude-code, cline, codex, continue, cursor, and opencode. Merged from 7 individual binding-\* packages.

## Installation

```bash
npm install @orqenix/binding-adapters
# or
pnpm add @orqenix/binding-adapters
```

## Usage

```typescript
import {} from "@orqenix/binding-adapters";
```
