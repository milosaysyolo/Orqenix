# @orqenix/binding-core

Orqenix binding core -- platform-agnostic interfaces for agent runtime bindings.

Defines the abstract interfaces, types, and contracts that specific binding adapters implement. Transport-agnostic; framework-agnostic.

## Installation

```bash
npm install @orqenix/binding-core
# or
pnpm add @orqenix/binding-core
```

## Usage

```typescript
import {} from "@orqenix/binding-core";
```
