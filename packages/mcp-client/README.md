# @orqenix/mcp-client

MCP client for Orqenix — consume external MCP servers

## Installation

```bash
npm install @orqenix/mcp-client
# or
pnpm add @orqenix/mcp-client
```

## Usage

```typescript
import {} from /* exports */ "@orqenix/mcp-client";
```
