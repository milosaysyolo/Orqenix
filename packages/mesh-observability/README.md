# @orqenix/mesh-observability

Structured logs, OpenTelemetry-compatible metrics, W3C traceparent propagation, and strict redaction for the Orqenix mesh.

## Installation

```bash
npm install @orqenix/mesh-observability
# or
pnpm add @orqenix/mesh-observability
```

## Usage

```typescript
import {} from "@orqenix/mesh-observability";
```

## Exports

- Structured logging pipeline with redaction
- OpenTelemetry-compatible metric counters and histograms
- W3C traceparent context propagation
- Strict PII redaction for mesh operations
