# @orqenix/plugin-lazy-loader

Reference-not-embed file content loader

## Installation

```bash
npm install @orqenix/plugin-lazy-loader
# or
pnpm add @orqenix/plugin-lazy-loader
```

## Usage

```typescript
import {} from /* exports */ "@orqenix/plugin-lazy-loader";
```
