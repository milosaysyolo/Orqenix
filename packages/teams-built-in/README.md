# @orqenix/teams-built-in

Built-in Orqenix team bundles (dev-team)

## Installation

```bash
npm install @orqenix/teams-built-in
# or
pnpm add @orqenix/teams-built-in
```

## Usage

```typescript
import { /* exports */ } from "@orqenix/teams-built-in";
```
