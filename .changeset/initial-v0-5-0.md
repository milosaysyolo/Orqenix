Initial public release of Orqenix v0.5.0 (Phase 5 — Memory Foundation Refactor).

Local-first mesh architecture for multi-agent AI systems: scope identity
(Ed25519), capability-based permissions, ChatKB with diff-only storage,
memory tiering with compress-as-memorize, hash-chained audit log, two-step
detach safety, and Phase 4 to Phase 5 migration tooling.
