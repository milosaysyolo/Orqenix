# Getting Help

Thanks for using Orqenix. Please choose the right channel for your question:

## 1. Read the docs first

- [Getting Started](./docs/getting-started.md)
- [Architecture overview](./docs/architecture.md)
- [FAQ](./docs/faq.md)
- [CHANGELOG](./CHANGELOG.md)

## 2. Search before asking

- [GitHub Issues, open and closed](https://github.com/milosaysyolo/Orqenix/issues?q=is%3Aissue)
- [GitHub Discussions](https://github.com/milosaysyolo/Orqenix/discussions)

## 3. Ask in the right place

| You want to... | Use |
|----------------|-----|
| Report a reproducible bug | [Open a bug report](https://github.com/milosaysyolo/Orqenix/issues/new?template=bug_report.yml) |
| Request a feature | [Open a feature request](https://github.com/milosaysyolo/Orqenix/issues/new?template=feature_request.yml) |
| Ask a how-to question | [Q&A in Discussions](https://github.com/milosaysyolo/Orqenix/discussions/categories/q-a) |
| Share what you built | [Show and tell](https://github.com/milosaysyolo/Orqenix/discussions/categories/show-and-tell) |
| Chat informally | Discord (waitlist): <!-- TBD: discord-invite --> |
| Report a security issue | [SECURITY.md](./SECURITY.md), do NOT open an issue |
| Discuss commercial / Pro | `hello@orqenix.dev` |

## Response expectations

Orqenix is currently maintained by a small core team. We aim to respond to
issues within **5 business days** and to security reports within **48 hours**.
Discussions are best-effort and community-driven.

If you need guaranteed SLAs, see the upcoming Orqenix-Pro support tier.
